# Changelog

Kept in sync with the in-app Changelog dialog (`index.html`) by hand --
update both on every change or same-session batch of changes.

## 2026-08-04

- Added a new Logo mode, its own top-level mode button alongside Text + Outline, Text + Shape, and QR Code + Text. Upload a PNG (auto-detects print-color regions via k-means clustering, adjustable "Colors to detect") or SVG (grouped by each shape's own fill color) logo -- its own silhouette becomes the die-cut outline (grown by an adjustable Outline slider, 0 = hug the silhouette exactly), and each detected color becomes its own paintable emboss/inlay layer on top, same mechanics as Die-cut Text mode's letters-plus-backing. The upload button and every logo-shaping setting (Size, Position, Rotation, Outline, Emboss height, Backing thickness, Outline color) live together in one left-panel drawer; Mounting Holes and Magnet Holes are on the right, same as the other modes. No text list -- a caption belongs in Die-cut Text mode instead.
- Added a logo overlay to Shape mode, independent of this new Logo mode: upload the same kind of PNG/SVG logo via a "Logo" drawer and place its color layers on top of whichever backing shape is picked (square/rectangle/circle/heart/star/hexagon/cross), sized/positioned/rotated on its own and clipped so it can't overhang the shape's edge. Has its own Logo On/Off toggle and Size/Position/Rotation/Emboss height sliders. The uploaded file and "Colors to detect" setting are shared with Logo mode -- one upload works either way, since it's the same image regardless of which mode uses it.
- Both logo features reuse the app's existing alpha-mask marching-squares tracer (already used for font/QR tracing) rather than a separate tracing implementation. The imported logo round-trips through undo/redo, Save/Load project JSON, and autosave, same as every other design state; Reset clears it.
- Fixed Inlay mode leaving a uniform Outline/backing-colored strip along the entire bottom edge and side walls of a logo's color regions (both in Logo mode and Shape mode's overlay) -- each color's recess now cuts the full backing depth instead of stopping 0.2mm short, so a color's own solid spans the full thickness and both faces show the logo's real colors. The 0.2mm floor that die-cut text still reserves (to stop a small letter's own recess from opening a hole through a much larger surrounding backing) isn't needed here: a logo color is always immediately backfilled by its own solid and sits edge-to-edge against its neighbors, so a full-depth cut can't create a void or a disconnected piece.
- Fixed a hairline sliver of Outline color still showing at the logo's own outer edge (and any concave notch in it, e.g. a speech-bubble tail) even with Outline set to 0 -- the master silhouette trace and each detected color's own trace come from different pixel masks, simplified independently, so their polygon boundaries rarely land on exactly the same vertices even though the underlying pixel sets are a perfect partition. The biggest detected color (almost always the background) is now computed as "whatever's left of the true silhouette after every other color's own shape is subtracted" instead of its own independently-traced boundary, closing the seam by construction with no overlap between colors (an earlier attempt at this via a small uniform grow on every color caused z-fighting between adjacent colors and was reverted).
- Added a Corner radius slider to Logo mode's outline (same erode-then-dilate rounding used by QR mode and Shape mode's square/rectangle), between Outline and Emboss height. Every detected color is clipped against the final rounded outline, so a corner that gets rounded off can't leave a color sticking out past the backing's actual edge.
- Fixed Logo mode's Corner radius doing nothing at 0 -- growing the outline by the Outline margin used offset()'s default Round join, which rounds every convex corner regardless of Corner radius (same bug QR mode's Outline trim had, fixed there the same way). The margin now grows with a Miter (sharp) join instead, so Corner radius is the only thing that rounds a corner off.
- Fixed the Emboss height slider (Logo mode and Shape mode's logo overlay) staying live in Inlay mode even though Inlay always cuts each color's recess as deep as it safely can and ignores this slider entirely -- now greyed out and relabeled "Emboss height (fixed by Inlay)" while Inlay is selected, matching how the die-cut text list's own Text height slider already behaves.
- Made the logo draggable directly in the 3D viewport, same click-and-drag as a line of text -- works for both Shape mode's logo overlay and standalone Logo mode's own logo. Grabbing any part of the logo (any detected color, or the outline in Logo mode) moves the whole thing together, updating the same Position sliders live. Under the hood, the drag system now supports a single shared position (the logo's) in addition to its original "one array element's own position" case, so this reuses the exact same mechanism text dragging already used rather than a separate implementation.
- Changed Shape mode's left-panel drawers (Shape size, Text) to start collapsed by default, matching Logo mode's own drawer -- only the shape gallery itself is visible right away.

## 2026-08-03

- Changed which drawer starts open on QR Code + Text mode's right panel: Size & Thickness now opens by default instead of Outline (Outline, Mounting Holes, and Magnet Holes all start collapsed). QR-mode-specific -- Die-cut and Shape mode still open on their own Outline drawer.
- Changed QR Code + Text mode's Outline to default Off (was On) -- the scannable QR pattern reads fine without a trim, and now that the caption also starts empty there's nothing at boot that needs a backing either. Matches Shape mode's Outline, which also defaults Off.
- Changed QR Code + Text mode's caption to start with 0 lines by default (previously always had one "Text 1" line pre-filled) -- add one with "+ Add text" when you actually want a caption, matching how removing the last line now works.
- Changed QR Code + Text mode's default caption text from "CAPTION" to "Text 1" (and "Text 2", "Text 3", etc. for lines added afterward), matching each entry's own "Text N" header instead of a fixed placeholder every line shared.
- Fixed the caption's X (remove) button in QR Code + Text mode being permanently disabled -- it was reusing Die-cut/Shape mode's "always keep at least 1 line" floor, which doesn't make sense for a caption that's optional on top of the QR code itself. It can now be removed all the way down to 0 lines, and added back with "+ Add text". Die-cut and Shape mode's own text lists are unaffected, still keeping their floor of 1.
- Moved QR Code + Text mode's Corner radius slider from Size & Thickness into the Outline drawer, since it shapes the trim as much as the backing.
- Fixed QR Code + Text mode's Outline trim always coming out rounded at the corners even with Corner radius set to 0 -- the trim is grown from the backing via an offset operation that rounds convex corners by default regardless of the input shape, so a sharp-cornered backing was still growing into a rounded trim. It now grows with sharp (mitered) corners instead, matching the backing's own Corner radius setting all the way down to a fully pointy 0.
- Added a Corner radius slider to QR Code + Text mode's Size & Thickness section, rounding the backing/trim's corners. Capped at the quiet zone's own width at render time (however far the slider is dragged) so rounding can never crop into the QR pattern's own modules -- the QR mark is always clipped against a plain, unrounded square regardless of this setting.
- Merged the QR caption's separate "Text Outline" drawer into the QR pattern's own preexisting "Outline" drawer -- one shared On/Off toggle and color now controls both the QR's picture-frame trim and the caption's own die-cut style backing, with each caption line's own "Text N Outline" slider living in that same drawer, same as die-cut mode's multiple text lines do. Outline now defaults On (was Off) since it also has to cover the caption's backing, which shouldn't start out as floating unconnected letters.
- Fixed the QR caption's own Outline (backing) bleeding/flickering against the QR pattern itself (visible as the QR's black/white modules showing striped artifacts through the purple outline) -- the earlier fix subtracted the QR mark from each caption LETTER but missed the caption's OUTLINE solid itself, which is why the letters looked correct but the outline behind them didn't. The QR mark now also carves the outline wherever the two genuinely overlap.
- Fixed z-fighting when a QR caption is dragged on top of the QR sign's own backing/trim or its pattern: the caption's own backing now carves the QR backing/trim out from underneath it (same "ordinary CSG subtraction, harmless no-op wherever there's no overlap" pattern as Magnet Holes elsewhere), and a raised caption letter dragged directly onto the QR pattern itself gets carved back rather than the QR modules -- the two stay separate, independently colored/positioned objects, they just no longer occupy literally the same space where they meet.
- Redesigned QR Code + Text mode's caption so it's a genuinely separate object from the QR code, not clipped to or reliant on the QR's own backing. Captions now work exactly like Die-cut Text mode's lines: each can grow its own die-cut style outline/backing from its letters (new per-line "Text N Outline" sliders in a new "Text Outline" section on the right panel, on by default, with its own color picker), fully independent of the QR pattern's own backing/trim/Outline. A caption can now sit anywhere on the plate -- beside the QR code, elsewhere entirely, or dragged to overlap it -- instead of being cut off wherever it left the QR's own footprint.
- Renamed QR Code mode to "QR Code + Text" and gave it its own caption text list, same as Die-cut and Shape + Text mode: add/remove lines the same "+ Add text" way, each its own independent object with its own font, size, color, position, rotation, and depth -- not a property of the QR code. Captions are clipped against the sign's full outer footprint (including the Outline trim band, if on), not just the QR code's own quiet zone, so a caption can sit on the trim border alongside the code. Magnet holes cut through caption text the same way they already cut through the QR mark and die-cut/shape text. The Text section is its own top-level left-panel area (like Shape mode's separate "Shape size" and "Text" sections), not nested inside the QR pattern's own settings. A newly added line starts positioned just below the QR pattern instead of dead-center on top of it, so it reads as a separate object from the start instead of looking fused to the code.
- Changed defaults: Inlay (flush) is now the default Print style instead of Emboss. On the right panel, only the Outline drawer is open by default in each mode now (Thickness/Size & Thickness, Mounting Holes, and Magnet Holes all start collapsed).
- Fixed QR Code mode's Outline shrinking the plate inward instead of growing it outward -- it was reusing Shape mode's trim behavior (erode a fixed-size backing to make room for the band), which for QR meant turning Outline on ate into the quiet zone around the pattern (and could reach the QR pattern itself with a thick enough Outline). Outline now grows the plate OUTWARD from the QR+quiet-zone footprint instead, so the scannable area is never touched -- the sign just gets bigger.
- Added a new QR Code mode, its own top-level mode button alongside Text + Outline and Text + Shape. Generate a QR code live from typed text/URL (via a locally-bundled encoder, works offline, error-correction level L/M/Q/H selectable) or import an existing QR code image and trace it into the design -- both paths feed the same canvas-raster-then-trace pipeline the Text modes already use for fonts, so touching QR modules merge into fewer, larger shapes instead of one piece per module. Settings: Overall size and Sign thickness sliders, an Outline picture-frame trim (on/off, color, thickness) separate from the QR's own always-present scannability quiet-zone margin, QR mark height in Emboss (Inlay always cuts as deep as it safely can, same as text), QR and backing colors, and the same Mounting Holes / Magnet Holes sections as the other modes (magnet holes cut through the QR mark itself, not just the backing, same fix as text got). QR mode has no text list -- it fully replaces the Text section for that mode.
- Moved each die-cut line's "Outline thickness" slider out of its own per-line entry and into the Outline drawer on the right panel, next to the master Outline on/off toggle it depends on. Now shows as "Text 1 Outline", "Text 2 Outline", etc., renumbering live as lines are added or removed.
- Simplified Mounting Holes' Corners position controls the same way: removed the "Corner loop position (from side edge)" Margin slider (it only ever affected the Corners x-position, and only alongside the Fine position (left/right) slider, which already covered the exact same term). The old default 10mm edge inset is now a fixed constant baked into the geometry, so existing designs look unchanged.
- Simplified Magnet Holes' Corners/Center position controls from 3 sliders down to 2: removed the "Corner hole position (from side edge)" Margin slider, since it was mathematically redundant with the Fine position (left/right)/(up/down) sliders -- both added into the exact same term, so any position reachable with Margin was already reachable with the fine sliders alone. The old default 10mm edge inset is now a fixed constant baked into the geometry, so existing designs look unchanged; the fine sliders now do all the adjusting.
- Fixed Magnet Holes only cutting into the backing, not into any text that happened to overlap the hole (a raised emboss letter or a recessed inlay letter would bridge across the hole uncut instead of being punched through with it). The hole is now subtracted from each text layer's own solid too, in addition to the backing/trim. Also fixed a bug where shape mode's magnet holes ignored the Hole depth slider entirely and always cut exactly to the backing's own thickness (a wrong variable was passed as the depth).

## 2026-08-02

- Added Magnet Holes (both modes): cuts a plain circular pocket into the back of the design for embedding a magnet -- the opposite of Mounting Holes, which fuse a loop on rather than cutting into the backing. None/Corners/Center placement with the same anchor pattern as Mounting Holes, plus adjustable hole diameter, depth, edge margin (Corners), and left/right + up/down position sliders. Blind by default; if the hole depth is set deeper than the backing's thickness it cuts straight through, doubling as a mounting hole. Die-cut mode's toggle is greyed out when Outline is off, same as Mounting Holes.
- Added an Outline option to Shape mode's backing: a colored border band inset from the shape's outer edge, same height as the backing -- a picture-frame-style trim for two-color printing. On/off toggle, color picker, and a Trim width slider in a new "Outline" section on the right panel. Built as its own non-overlapping solid (not layered on top of the backing), so it exports as a clean second paintable color; Mounting Holes fuse to the trim instead of the backing fill when both are on, since the loop sits right at the edge where the trim actually is.
- Fixed die-cut Mounting Holes (Corners/Center) anchoring to the whole backing's bounding box instead of the top line's own -- dragging a lower line wider or further sideways than the top line could push the top line's loops off it entirely. Now anchored to whichever line is actually highest, so they stay on it regardless of what other lines are doing.
- Added Mounting Holes (both modes): adds a small loop with a hole through it, fused to the top of the backing for hanging on a nail/screw -- same idea as Clicker Generator's keyring loop, not a hole cut into the backing itself. Choose None, Corners (one loop near each top corner of the backing's bounding box), or Center (one loop, centered, near the top edge), with adjustable loop outer diameter, hole diameter, how far in from the side edge each Corners loop sits, and fine left/right + up/down position sliders to nudge placement -- the left/right one is mirrored for Corners, so one slider spreads or pulls in both loops together instead of needing two. Die-cut mode's toggle is greyed out when Outline is off, since there's no backing to fuse it to.
- Added 10 Google Fonts to the Font dropdown, picked for thick/even strokes that hold up when traced to a 3D-printable outline: Montserrat, Poppins, Bebas Neue, Anton, Fredoka, Baloo 2, Righteous, Archivo Black, Luckiest Guy, and Bungee. Loaded from Google's CDN (see License dialog).
- Moved the Total/Backing thickness slider out of the Outline (die-cut backing) drawer into its own "Thickness" section on the right panel, since it's the sign's overall thickness, not an outline-specific setting.
- Added a total size readout in the top-right of the viewport (Width x Depth x Height, mm), updating live as the design changes.
- Restored the full "Free to use for personal or commercial projects..." wording for the hint text under the Buy Me A Coffee/Boost links (had been over-shortened); Disclaimer dialog left as its original warranty/license text.
- Added a bug icon next to the "Report a Bug" link; changed the bug-report email from a personal address to info@bashcreates.com; added a note in the Report a Bug dialog inviting Google Fonts suggestions.
- Fixed Position (left/right)/(fwd/back) sliders showing long floating-point decimals after dragging a line in the 3D viewport (e.g. "34.728193745mm") -- dragged values are now rounded to 0.1mm, both going forward and for values already carrying drift.
- Moved the "Outline (die-cut backing)" section from the left panel to the right panel, above Export format -- still only shown in Die-cut Text mode.
- Added Buy Me A Coffee and Boost on MakerWorld links to the right panel, matching the original Clicker Generator project.
- Added "Align lines": ONE global Manual/Left/Center/Right toggle for each mode's whole text list (not a per-line setting -- an earlier per-line version was confusing, since a lone aligned line had nothing to measure against unless a sibling line also opted in). Left/Center/Right lines up every line in the list to a shared edge (the widest line), overriding each line's own Position (left/right) slider while active. Useful for stacking different-sized lines added as separate objects, since one text box's Line spacing/alignment forces every line inside it to share one size/font.
- Added Left/Center/Right line alignment buttons per text box, for when a single box has 2+ lines (typed with a line break) -- controls how those lines line up relative to each other, independent of the box's own overall position.
- Added drag-to-move: click and drag any line of text directly in the 3D viewport to reposition it (updates the same offsetX/offsetY as the Position sliders, which stay in sync live). Hover/drag highlighting and a grab/grabbing cursor show what's draggable; orbiting is disabled for the duration of a drag and re-enabled on release; one undo step per drag, not one per pixel moved.
- Renamed the backing-height sliders (die-cut Outline height, Shape backing height) to say "Total thickness" in Inlay mode and "Backing thickness (text adds height on top)" in Emboss mode, since only Inlay's recess keeps the slider value as the true total height.
- Added a per-line Character spacing slider (both modes).
- In Inlay mode, each line's Text height slider is now greyed out (it doesn't apply -- the recess is always cut as deep as it safely can be into the backing) and relabeled to say so; toggling Emboss/Inlay now refreshes both text lists live.
- Reworded the Line spacing slider to "Line spacing (if this box has 2+ lines)" to clarify it only affects line breaks typed inside one text box, not separate lines added via "Add line."
- Added Disclaimer, License, Changelog, and Report a Bug links/dialogs to the sidebar.
- Fixed a bug where the Text lists (both modes) failed to render and the Add Line/Add Text buttons did nothing, caused by a stale variable reference in the shared list-building code.
- Made each line in Die-cut mode responsible for its own outline thickness (margin) instead of one shared value for the whole design -- lines with different thicknesses still fuse together where they overlap.
- Split Die-cut mode's single text block into independent per-line text elements (add/remove lines, each with its own font, size, depth, position, rotation, and color).
- Added an Emboss/Inlay print-style toggle -- Inlay cuts text as a flush recess into the backing instead of raising it, for printing text-side-down with no supports.
- Fixed the die-cut outline only showing up behind closed letter counters (like the hole in an "O") instead of growing around the whole word -- a loop-winding-direction bug in the outline generator.
- Initial build: Die-cut Text mode (type text, optional connecting outline) and Shape + Text mode (pick a backing shape, add independently-placed text), 3MF/STL export for multi-color printing, undo/redo, save/load project, autosave. Ported from Clicker Generator's Manifold/Three.js plumbing, with all keychain-button-specific features removed.
