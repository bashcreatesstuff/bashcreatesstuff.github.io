Yamanote Line Train Screen Saver

A free Windows screensaver that recreates the passenger information screens on Tokyo's Yamanote Line E235 trains. It rides the real loop with all 30 stations, and every monitor becomes its own car.

Download for Windows v1.0 · 2.2 MB Live demo Source code 74 KB

What it does

The real loop

All 30 stations with real running times, transfer lines and exit names. The train runs both directions around the loop and stops at every station.

One car per monitor

Each screen is its own car, numbered left to right, and no two screens show the same thing at once. Wide monitors get two or three cars side by side.

Japanese, kana and English

The header cycles through kanji, kana and English like the real screens, while the lower screen moves between the line maps, platform guide, transfers and train info.

Settings that matter

Dim the screens down to 20% brightness and switch between a 24-hour and 12-hour clock. Everything runs offline, fonts included.

Install on Windows

  1. Download the zip and unzip it. Copy TrainScreen.scr somewhere it can stay, like C:\Windows (Windows will ask for admin approval). If you install it from your Downloads folder and later delete it, the screensaver stops working.
  2. Right-click TrainScreen.scr and choose Install. Screen Saver Settings opens with Yamanote Line Train Screen selected.
  3. Click Settings... to set the brightness and clock style. Back in Screen Saver Settings, the Wait box sets how many minutes your PC sits idle before the screensaver starts. Click OK when you're done. Use Preview to try it right away, and move the mouse to exit.
"Windows protected your PC"? That message shows up for any small program that isn't code-signed, which costs a yearly fee most hobby projects skip. Click More info, then Run anyway. Some browsers also warn about downloading screensaver files, which is why it comes in a zip.

Mac, Linux and Lively Wallpaper

The live demo is the same display as a single web page, so it runs anywhere with a modern browser. Press F11 for full screen.

On a Mac, a free screensaver like WebViewScreenSaver can show the demo page. With Lively Wallpaper on Windows, use the HTML file from the zip and set it to span all screens.

Demo page options

Add these to the end of the demo address:

  • ?dim=40 makes it 40% darker
  • ?clock=12 uses a 12-hour clock
  • ?cars=3 shows three cars side by side
  • ?car=4 starts numbering at car 4

Combine them with &, like ?dim=40&clock=12.

Requirements

Windows 10 or 11 with the Microsoft Edge WebView2 Runtime, which comes with Windows 11 and nearly every up-to-date Windows 10 PC. If the screen stays black, install WebView2 from Microsoft. No internet connection is needed once it's installed.
